# Let's Build a Zoo — русификатор

**Автор: STEANDR**

Неофициальный русский перевод для Windows-версии Let's Build a Zoo.

## Скачать

Готовый архив размещается в [Releases](https://github.com/STEANDR/lets-build-a-zoo-russian/releases).
Скачивайте `Lets_Build_a_Zoo_RU_STEANDR_Latest.zip` из блока **Assets**.

Если релизов пока нет, архив ещё не опубликован. Архивы **Source code** не содержат готового русификатора.

## Что входит

- Русский язык отдельным пунктом в меню.
- Файл локализации на **8 143 записи**.
- Обычный шрифт **Segoe UI** со сглаживанием и семью наборами размеров.
- Исправление ошибки чтения CSV, вызывавшей вылет при запуске в ранней сборке.
- Инструкция по установке и откату.

Перевод машинный с выборочной ручной правкой. Исправления формулировок приветствуются.

## Совместимость

Сборка подготовлена для **Let's Build a Zoo, Windows, build 1.1.16**.
Для других версий совместимость не проверена.

## Установка

1. Полностью закройте игру.
2. В Steam откройте **Библиотека → Let's Build a Zoo → Управление → Просмотреть локальные файлы**.
3. Сохраните резервные копии `LetsBuildAZoo.dll` и `Content/CSV/Localization/Russian/Russian.csv` вне папки игры. При обновлении русификатора сохраните также прежние `RussianReadable*.xnb`.
4. Распакуйте скачанный ZIP.
5. Скопируйте **оба элемента** из архива в папку игры:
   - `LetsBuildAZoo.dll`;
   - папку `Content`, объединив её с существующей и подтвердив замену файлов.
6. Если Windows запросит права администратора для копирования, подтвердите действие.
7. Запустите игру и выберите **Русский** в настройках языка. Пункт находится после итальянского; при необходимости прокрутите список.

**Не удаляйте существующую папку Content. Одной замены DLL недостаточно.**

Обычный путь к игре:

```text
C:\Program Files (x86)\Steam\steamapps\common\Let's Build a Zoo
```

## Если возникли проблемы

**Игра вылетает при запуске:** убедитесь, что установлены все файлы одного актуального пакета, включая исправленный `Russian.csv`, и что версия игры совпадает с указанной выше.

**Вместо букв звёздочки или отсутствует текст:** проверьте наличие всех семи файлов `RussianReadable*.xnb` в `Content/Fonts` и полностью перезапустите игру.

**Нет пункта «Русский»:** проверьте, что DLL скопирована именно в папку запускаемой игры.

Если проблема сохраняется, откатите изменения и [создайте Issue](https://github.com/STEANDR/lets-build-a-zoo-russian/issues/new). Укажите версию игры, что произошло, последовательность действий и приложите снимок экрана или текст ошибки. Для ошибок перевода приведите текущую фразу и предложенный вариант.

## Откат

Закройте игру и верните файлы из резервной копии. Если оригинальная DLL не сохранилась, проверка целостности файлов в Steam восстановит официальные файлы и отменит их модификации.
